# AreaMatrix Visual Prototypes

本目录保存不作为产品源事实的视觉原型。它们可以用于展示、讨论和回溯，但不替代 `docs/`、`.ai-governance/` 或 `workflow/versions/**`。

## 目录

- `landing/`：AreaMatrix landing / welcome 页面原型。
- `workspace/`：AreaMatrix workspace 界面 mockup。

## 约定

- 原型可以引用 `assets/brand/final/` 的权威品牌资产。
- 一次性修补或检查脚本放在对应原型的 `tools/` 子目录。
- 如果原型内容需要成为长期产品行为，先同步到 `docs/` 的对应产品、架构或 UX 文档。
- 构建产物、截图缓存和本机运行日志不要放入本目录。
