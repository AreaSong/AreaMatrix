# AreaMatrix 产品概览

> AreaMatrix 是面向 macOS 用户的本地优先资料管理应用，负责安全接管、导入、组织、搜索和追溯普通文件夹中的资料。
>
> 阅读时长：约 5 分钟。

## 产品定位

AreaMatrix 服务个人用户和小团队的本地资料整理需求。资料库仍是普通文件夹，用户可以继续使用 Finder、终端、编辑器和同步工具访问其中的文件。应用通过 SQLite 保存标签、笔记、历史、配置和索引，但不把文件锁入专有容器。

核心价值由四个动作组成：

1. **接管**：安全使用已有目录，不要求先搬迁或重排文件。
2. **归档**：通过移动、复制或仅索引模式导入资料。
3. **组织**：使用分类、标签、搜索、智能列表、批量操作和可选 AI 降低整理成本。
4. **追溯**：保存改动日志、操作历史、笔记、诊断和恢复信息。

## 正式平台

macOS 原生应用是 AreaMatrix 的正式产品界面。Rust Core 保持平台无关，但其他平台客户端不属于正式产品能力，也不进入用户指南。

## 核心用户

- 需要长期管理合同、票据、论文、代码、设计稿和截图的个人用户。
- 希望保留普通文件夹结构，同时获得分类、搜索和改动历史的专业用户。
- 重视本地存储、文件可退出性和远程 AI 数据控制的用户。

AreaMatrix 不定位为企业文档权限系统、云端团队协作平台、专有素材容器或笔记双链工具。

## 产品承诺

- 接管已有目录时不移动、不重命名、不删除、不覆盖任何已有文件。
- 自动生成内容默认只写入 `.areamatrix/generated/`。
- 应用不得覆盖用户已有的 `README.md`。
- 导入成功后文件系统和数据库必须同时可见；失败时不得留下最终目录半成品。
- 删除 `.areamatrix/` 不得导致用户文件丢失。
- 远程 AI 默认关闭，启用时必须明确配置、说明数据流向并经过隐私规则评估。

## 产品结构

AreaMatrix 使用一个 macOS 主窗口。首次启动、资料库工作区、导入、搜索、设置、AI、冲突处理和恢复通过窗口内路由、Sheet、Popover、Panel 与确认对话框组织。

完整界面和入口见[产品界面地图](product-surfaces.md)，正式能力见[产品能力](capabilities.md)，常见任务见[用户工作流](workflows.md)。

## 获取方式

AreaMatrix 目前通过源码构建使用。签名、公证、正式安装包和外部长期使用证据属于分发验证，不改变产品合同，但会限制正式安装包的发布声明。
