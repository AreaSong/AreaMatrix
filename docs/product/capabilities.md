# AreaMatrix 产品能力

> 本文列出 macOS 产品已经进入代码、Bridge 和测试体系的正式能力，以及不属于正式产品的方向。
>
> 阅读时长：约 8 分钟。

## 资料库生命周期

- 创建空资料库。
- 打开已初始化资料库。
- 接管已有非空目录，并建立 AreaMatrix 元数据和索引。
- 校验路径、权限、初始化状态和 schema 兼容性。
- 执行启动恢复、扫描会话恢复、诊断和元数据修复。

接管只允许创建 `.areamatrix/` 内部状态和经用户选择的专属概览，不改变已有用户文件布局。

## 导入与冲突

- 单文件、批量文件和文件夹导入预检。
- 移动、复制和仅索引三种存储模式。
- 分类预测、命名选项、重复检测和同名冲突处理。
- 导入进度、取消控制、结果摘要和恢复提示。
- Replace 二次确认、批量冲突决策和支持的 Undo 路径。

应用层会编排导入预览和队列。Core 仍以现有分类、导入和冲突合同提供底层行为；尚未提供统一的 `preview_import` 或流式队列 API。

## 浏览与详情

- 资料库目录树和文件计数。
- 文件表格、排序、单选与多选。
- 元数据、来源、路径、大小和存储模式展示。
- 改动日志时间线。
- 伴生笔记读取与编辑。
- 使用系统默认应用打开文件、在 Finder 中显示和复制路径。

## 搜索与组织

- 文件名、笔记、路径和元数据搜索。
- 筛选条件、搜索空态和查询错误恢复。
- Saved Search 的创建、编辑、删除和执行。
- Smart List 的执行和管理。
- 标签增删、标签筛选和批量加标签。
- 批量改分类、批量重命名和批量删除确认。
- 分类纠正、规则保存、影响预览和分类器编辑。
- 命令面板统一检索命令、文件和智能列表。

## Undo 与 Redo

- 操作历史查看。
- 对受支持动作执行 Undo 和 Redo。
- 批量标签、批量重命名、文件操作和导入冲突等能力拥有各自的恢复合同。

Undo/Redo 不代表任意文件系统变化都可以撤销。界面必须根据 Core action log 和动作资格显示可用状态。

## 语义搜索与 AI

- 建立、取消和查询语义索引。
- 语义结果与普通搜索结果分组展示。
- 本地模型状态查看。
- 可选远程 Provider 配置和受限连通性探测。
- AI 分类建议、摘要编辑、标签建议和失败回退。
- AI 调用日志和隐私规则管理。

远程调用的实际可用性取决于用户配置、凭据、模型、网络和隐私规则。未满足条件时，产品应显示不可用或回退状态，不伪造成功结果。

## 外部变化与 iCloud

- 监听和同步 Finder 或终端产生的外部文件变化。
- 保存和恢复 watcher cursor 与健康状态。
- 检测 iCloud 路径和占位符状态。
- 列出和审阅 iCloud 或一般同步冲突。
- 对冲突方案进行预览、确认和应用。

iCloud 下载、冲突应用和外部变化回流属于高风险平台行为，必须保持显式状态和确认边界。

## 设置与诊断

- 通用设置。
- 资料库设置和健康检查。
- 分类器和规则设置。
- 集成与平台能力状态。
- AI 模型、远程 Provider 和隐私设置。
- 高级 repository metadata snapshot、About 脱敏文本诊断和关于信息。

## 不属于正式产品的方向

- iOS、Windows、Linux 客户端。
- OCR 专用工作流。
- 独立的语义相似文件检测界面。
- 多设备同步协议和自托管同步服务。
- 公开 SDK、插件系统和企业权限模型。

这些方向只有在实现、测试和产品边界确认后，才能进入正式能力清单。
