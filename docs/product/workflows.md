# AreaMatrix 用户工作流

> 本文用稳定用户任务描述 AreaMatrix 的产品闭环，并链接到对应用户指南和安全边界。
>
> 阅读时长：约 7 分钟。

## 建立资料库

1. 启动 AreaMatrix。
2. 选择空目录、已有目录或已经初始化的资料库。
3. 应用校验路径、权限和初始化状态。
4. 空目录可以创建资料库；非空目录需要确认接管。
5. 接管只创建 `.areamatrix/` 元数据并扫描现有内容。
6. 完成后进入资料库工作区。

已有文件、目录结构、项目配置和 `README.md` 保持原样。

## 导入资料

1. 从 Finder 拖入文件或文件夹，或使用工具栏导入入口。
2. 应用执行分类、重复、命名、目标路径和平台状态预检。
3. 用户选择移动、复制或仅索引模式。
4. 用户审阅重复文件、同名冲突和 Replace 风险。
5. 应用在确认后执行导入并展示逐项进度。
6. 完成后更新文件列表、目录树、索引、事务性 `change_log` 和相关概览；启用运行观测时另行产生不影响提交结果的
   runtime event。

失败导入不得留下最终目录半成品；源文件是否保留由存储模式和执行结果决定。

## 浏览和理解文件

1. 在侧边栏选择目录、智能列表或标签。
2. 在文件表格中排序、选择或多选。
3. 在详情区域查看元数据、来源和路径。
4. 在改动历史中查看 `change_log` 记录的导入、重命名、移动、删除和外部变化。
5. 在笔记中补充与文件关联的 Markdown 内容。

## 搜索和组织

1. 使用普通搜索查询文件名、笔记、路径和元数据。
2. 使用筛选条件缩小分类、标签、时间或其他范围。
3. 保存常用查询，或使用 Smart List 重复执行组织规则。
4. 按需建立语义索引并查看语义搜索结果。
5. 通过标签、批量改分类、批量重命名和命令面板执行整理任务。
6. 对支持的动作使用 Undo 或 Redo。

## 使用 AI 能力

1. 在设置中检查 Core 当前配置的本地模型状态，或明确配置远程 Provider。
2. 查看模型状态和远程探测结果。
3. 配置允许或拒绝的数据范围和隐私规则。
4. 在分类、摘要、标签或语义搜索界面显式触发能力。
5. 审阅建议后决定应用、修改或放弃。
6. 在调用日志中查看净化后的调用记录。

AI 建议不会自动替代用户文件和分类决定。远程能力不可用或不允许时，产品应回退或显示阻断原因。

## 处理外部变化和冲突

1. Finder、终端或同步工具修改资料库文件。
2. watcher 将外部变化同步回 AreaMatrix 元数据和界面。
3. 对无法自动协调的变化，应用显示冲突入口。
4. 用户审阅候选版本、resolution 和文件影响。
5. 高影响 resolution 在二次确认后应用。

数据库跟随文件系统存在性和位置变化，不得复原用户已经在文件系统中明确完成的删除或移动。

## 恢复资料库

1. 启动时检查未完成导入、扫描会话和元数据状态。
2. 对可恢复状态显示重试或继续入口。
3. 对数据库元数据问题显示修复影响和确认条件。
4. 诊断导出先说明内容并执行脱敏，不自动上传。
5. 修复或重新索引只处理 AreaMatrix 元数据，不修改用户文件内容。

## 定位和分享未知问题

1. 在设置窗口的独立 Diagnostics Tab 查看模式、保留期限、磁盘预算、丢弃计数和 writer/回调健康状态。
2. 需要复现时显式开启有时限的诊断或开发者模式；模式到期、下次启动或用户关闭后按所选策略回退。
3. 问题发生后标记 incident，冻结有界的前后事件窗口；该动作不录屏、不记录指针或逐键输入。
4. 在活动视图或 Trace Console 中按 session、trace、operation、action、component、severity 和 outcome 查看因果链。
5. 保存 `.amdiagnostic` 前审阅事件范围、隐私报告、预计大小，以及文件名、完整路径和 repository metadata
   snapshot 等相互独立的敏感选项；当前不支持添加任意用户文件附件。
6. 包只在用户选择的位置本地生成，不自动上传；接收方可离线打开并验证 checksum 和安全限制。
7. 用户可以删除 `memory_only` 或 `manifest_owned` incident，或删除所有受管理本地日志；`read_only` 历史 incident、
   未知文件和用户资料库内容保持不变。异常退出恢复的只读 incident 只用于审阅，不自动恢复文件。
