# 设置

> 设置界面管理应用行为、资料库、分类器、集成、AI、诊断和关于信息。
>
> 阅读时长：约 5 分钟。

## 通用设置

配置默认存储模式、概览策略和其他应用偏好。改变默认值只影响后续操作，不应静默重写已有文件。

General 只显示设备上的应用界面语言摘要，并提供前往“语言”页的入口。语言页中的界面语言选项为跟随系统、
简体中文和 English。切换会立即刷新菜单、窗口、
按钮、错误和辅助功能文案，不关闭当前页面、不清空草稿，也不重置正在进行的业务状态。日期、数字和文件
大小仍按 macOS 当前地区格式显示，不随界面资源语言改变。跟随系统只看首选语言第一项；第一项不支持时
直接显示 English，不继续扫描后续偏好。Welcome 右上角切换的是同一个界面语言。系统文件选择器、系统
菜单和 macOS 权限提示由系统决定语言，可能与 AreaMatrix 界面语言不同。

当选择“跟随系统”时，应用启动、重新进入前台或收到系统 locale 变化通知会重新解析并刷新所有窗口；
显式中文或 English 不跟随系统变化。Welcome 控件单击按“跟随系统 → 简体中文 → English → 跟随系统”
循环，不弹出菜单，并通过 tooltip 与 VoiceOver 说明当前模式。
紧凑控件使用带自动标识的地球表示跟随系统、“中”表示简体中文、“EN”表示 English；跟随系统的完整说明
还会显示当前解析结果。语言页中的界面语言和资料库内容语言是两套独立设置；右上角快捷控件只切换界面语言。

## 语言设置

语言页同时展示界面语言和当前资料库内容语言。界面语言是设备级设置并立即生效；资料库内容语言按资料库
保存，选项为跟随界面、简体中文和 English。两者可以任意组合，例如英文界面配中文生成内容。

资料库内容语言保存使用 revision CAS。保存只更新语言策略，不自动改写已有概览或 AI 内容；选择“跟随界面”
时，之后切换界面语言会立即更新内容目标语言和概览状态，但仍不会自动生成。

语言页还显示生成内容的目标语言与来源状态。需要统一已有概览时，用户从这里显式执行预检、暂存和提交；
恢复入口也留在同一流程中。该操作只处理受管理的概览目标，不处理 AI 内容、`README.md` 或用户文件。

## 资料库设置

查看资料库路径、配置状态、元数据存在性、健康检查和平台能力。更换资料库前确认目标目录，切换不会搬迁旧资料库。

Repository 只显示资料库内容语言摘要并提供前往“语言”页的入口。资料库内容语言只在 Language 中编辑，
按资料库保存，选项为跟随界面、简体中文和 English。它控制内置
分类显示名、目录树和之后生成的概览或 AI 自然语言结果，不翻译文件名、路径或正文。保存设置本身不重写
既有内容；之后正常导入、重命名、修复或外部同步如果本来需要刷新概览，会使用新选择。

保存后分类显示、目录树和语言摘要立即刷新；已生成 overview 与 AI 内容保持原样。不同 overview 可以暂时
保留不同历史语言，只有用户显式执行“重新生成全部概览”才会原子统一 `.areamatrix/generated/**` 和合法
`AREAMATRIX.md` managed block。该操作不处理 AI 摘要、`README.md` 或用户内容。
保存提示会说明实际保存的策略、当前解析语言以及现有内容未被重写；是否显示重新生成入口由 overview
provenance 状态决定。
Language 会根据生成 provenance 显示尚未生成、已同步、需要重新生成、语言/格式混合或来源未知；需要
重新生成时会分别说明语言不同、格式过期、缺少目标或存在失效目标。“混合”表示存在多个可信语言/格式，
没有可信记录或当前文件与记录 hash 不符时保持未知。应用不会从文字内容猜测语言；除已同步外，用户可显式
重新生成使其收敛，普通后台更新不会静默覆盖来源未知的生成文件。

多窗口同时编辑时使用 revision CAS。冲突不会自动覆盖、重试或静默合并：当前草稿保持可见，用户选择放弃
并载入最新值，或在最新 revision 上审阅 dirty fields 后再次保存。
审阅界面只针对 dirty fields 显示原保存值、最新持久化值和本地草稿。审阅只更新可见保存基线，不执行写入；
即使字段看似不重叠，也必须再次明确保存，不提供强制覆盖。

旧资料库的兼容别名会保留原值供浏览，只有用户明确保存时才写成规范选项。不支持的非空值会持续显示
原值和警告；资料库仍可浏览，但生成入口和分类规则的任何修改保持不可用，直到用户明确选择支持值。
完全没有可证明语言策略的旧资料库同样显示为未知，不根据现有文字或当前界面猜测；用户明确选择规范策略
后才恢复生成与分类修改。
这类资料库仍可浏览，并持续显示非阻断的设置提示。内容语言选择器初始不选中任何值，避免把默认值当成
用户决定；选择“跟随界面”时同时显示当前解析语言。只有明确保存后才解除生成阻断，保存不会重新生成
既有内容。

## 分类器设置

查看、编辑和校验分类规则，预览规则影响，并从错误状态恢复。保存前修复语法和语义错误。
编辑器一次只修改打开 draft 时冻结的编辑语言；切换“简体中文 / English”前若有修改，必须保存、放弃或
取消。编辑期间资料库 policy 改变会要求重新加载，避免覆盖另一语言的显示名或说明。
当前编辑语言没有显式值时，输入框保持空白，回退结果只显示在独立的只读预览中；预览不会自动保存为翻译。

## 集成设置

查看 iCloud 和平台能力状态。检测结果不应隐式触发占位符下载或冲突应用。

## AI 设置

管理本地模型、远程 Provider、凭据、隐私规则、调用日志和失败回退。远程 AI 默认关闭。
调用日志中的 `Privacy rules checked = yes` 表示请求实际经过隐私评估，不等于命中了规则；命中的规则
会单独显示。旧日志无法证明是否检查过时显示为 `not recorded`。

## 高级与诊断

查看诊断、恢复和平台差异。repository snapshot 可能包含路径、文件名、标签、笔记和其他 metadata；
About 文本诊断按专用合同脱敏。导出前检查内容和隐私说明，AreaMatrix 不自动上传诊断产物。
