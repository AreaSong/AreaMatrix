# 常见问题与排障

> 本文提供用户侧的安全排障顺序；开发构建和底层日志问题见开发排障手册。
>
> 阅读时长：约 5 分钟。

## 资料库无法打开

1. 确认目录仍存在并可读。
2. 检查是否选择了正确的资料库根目录。
3. 使用界面中的重试和诊断入口。
4. 如界面提供 metadata repair，先阅读影响再确认。

不要通过删除用户文件或整个资料库目录解决元数据错误。

## 导入失败

- 查看逐项结果和错误原因。
- 确认来源文件仍存在并可读。
- 检查目标目录权限、重复文件和同名冲突。
- iCloud 文件未下载时，等待同步或按界面提示处理。
- 重试前确认最终目录没有半成品；应用应自动保持这一不变量。

## 搜索没有结果

- 清除不需要的筛选。
- 检查当前目录、标签或 Smart List 上下文。
- 区分普通搜索与语义搜索。
- 语义搜索需要可用模型和已建立的索引。

## AI 功能不可用

- 检查本地模型或远程 Provider 状态。
- 检查隐私规则是否允许当前任务。
- 确认远程凭据仍可用。
- 查看调用日志和失败回退说明。

不要在 issue、诊断或截图中公开 API key、Authorization header 或完整敏感路径。

## 外部改动未出现

- 刷新资料库状态。
- 查看 watcher 或集成诊断。
- 检查文件是否仍为 iCloud 占位符。
- 对长期未同步的状态使用界面提供的恢复或重新索引入口。
