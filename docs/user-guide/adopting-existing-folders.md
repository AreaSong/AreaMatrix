# 接管已有目录

> 接管让一个已有文件夹成为 AreaMatrix 资料库，同时保持其中的文件、目录和项目结构不变。
>
> 阅读时长：约 5 分钟。

## 接管前

- 确认目录可读，并为需要写入 AreaMatrix 元数据的用户提供写权限。
- 如目录由 iCloud 或其他同步工具管理，先确认同步状态和占位符情况。
- 不需要提前移动、改名或重新分类现有文件。

## 接管过程

1. 在首次启动或更换资料库时选择非空目录。
2. 查看接管说明和路径校验结果。
3. 确认只创建 `.areamatrix/` 内部状态。
4. 等待扫描现有目录并建立索引。
5. 扫描完成后，在主工作区核对目录树和文件列表。

## 安全承诺

接管不得：

- 移动、重命名、删除或覆盖已有文件。
- 重排已有目录。
- 修改项目的 `.git/`、配置、源码或已有 `README.md`。
- 把扫描失败误报为接管完成。

扫描中断时，应用保存扫描会话并提供继续、重试或诊断入口。

## 接管后

已有文件以 indexed/adopted 语义进入元数据。之后通过 AreaMatrix 导入的新文件仍按用户选择的存储模式和目标位置处理。
