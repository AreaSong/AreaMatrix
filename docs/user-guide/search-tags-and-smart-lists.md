# 搜索、标签与智能列表

> AreaMatrix 提供普通搜索、筛选、Saved Search、Smart List、标签和可选语义搜索。
>
> 阅读时长：约 6 分钟。

## 普通搜索

在搜索入口输入文件名、路径、笔记或元数据关键词。使用筛选 Popover 限定分类、标签、时间或其他可用条件。查询失败和无结果是不同状态，失败时使用重试或调整条件。

## Saved Search

将常用查询保存为 Saved Search，以后可以重复执行和编辑。删除 Saved Search 只删除查询定义，不删除匹配文件。

## Smart List

Smart List 以保存的规则组织动态结果。结果会随资料库状态变化，不是静态文件副本。

## 标签筛选

从侧边栏或详情区域选择标签，查看跨目录匹配结果。标签筛选不改变文件分类或位置。

## 语义搜索

语义搜索需要可用的 embedding 能力和索引：

1. 查看索引状态。
2. 按需开始或取消索引构建。
3. 输入自然语言查询。
4. 区分语义结果、普通结果和回退状态。

本地或远程模型不可用、隐私规则不允许或索引未完成时，界面应说明原因并提供普通搜索等替代路径。
