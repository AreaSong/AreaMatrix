# 整理文件

> AreaMatrix 使用分类、标签、批量操作、笔记和操作历史整理资料库中的文件。
>
> 阅读时长：约 6 分钟。

## 浏览和选择

在侧边栏选择目录、智能列表或标签，在文件表格中排序、单选或多选。详情区域显示元数据、日志、笔记、标签和可用文件操作。

## 分类与规则

- 导入时查看分类预测并按需调整。
- 对错误分类执行纠正。
- 选择是否把纠正保存为长期规则。
- 在应用规则前查看影响预览。
- 在设置中编辑和校验分类器配置。

## 标签

- 在文件详情中添加或移除标签。
- 使用标签筛选资料库。
- 对多选文件批量添加标签。
- 审阅 AI 标签建议后决定应用。

标签是横跨目录分类的组织方式，不会自动移动文件。

## 批量操作

支持的批量任务包括加标签、改分类、重命名和删除/移除索引。执行前检查选中数量、目标、冲突和不可执行项目。

删除界面必须区分移至废纸篓和仅移除索引。Index-only 文件不得因移除索引而删除外部源文件。

## Undo 与 Redo

使用菜单、键盘入口、toast 或 Undo 历史 Sheet 查看可恢复动作：

- `Command-Z` 打开当前工作区的 Undo 历史。
- `Shift-Command-Z` 执行最近可用的 Redo。
- `Option-Command-Z` 从应用菜单打开 Undo 历史。

只有 Core action log 标记为可撤销或可重做的动作才会启用；外部 Finder 变化和部分高风险动作可能不支持恢复。

## 命令面板

按 `Command-K` 打开命令面板。它可以搜索命令、文件和 Smart List，并路由到导入、设置、搜索、文件定位、分类规则及批量操作。空资料库或当前选择不满足条件时，对应命令会禁用；删除、Replace 等高影响操作仍会进入预览或确认界面，命令面板不会绕过安全门禁。
