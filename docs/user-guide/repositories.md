# 创建和打开资料库

> 资料库是用户选择的普通文件夹；AreaMatrix 在其中维护文件，并将应用元数据保存在 `.areamatrix/`。
>
> 阅读时长：约 5 分钟。

## 创建新资料库

1. 在欢迎界面选择一个空目录。
2. 查看路径、权限和平台能力检查结果。
3. 确认创建资料库。
4. 等待初始化完成后进入主工作区。

初始化会创建 `.areamatrix/`、数据库、配置和必要的默认资源。自动概览默认写入 `.areamatrix/generated/`。

## 打开已有资料库

选择已经包含 `.areamatrix/` 的目录。应用会检查配置、schema、恢复状态、目录树和文件列表。出现错误时，不要直接删除元数据；优先使用界面提供的重试、诊断或修复入口。

## 更换资料库

从设置或资料库错误界面选择其他目录。切换资料库不会自动移动旧资料库中的文件，也不会合并两个资料库。

## 文件与元数据

- 文件存在性、内容和位置以文件系统为准。
- 标签、笔记、历史、配置和索引保存在 AreaMatrix 元数据中。
- 删除 `.areamatrix/` 会丢失应用元数据，但不得删除资料库中的用户文件。
