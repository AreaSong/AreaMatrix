# Workflow References

本目录保存 workflow 相关的参考资料和未来构想。这里的文件不是当前 AreaMatrix 产品源事实，也不是可直接执行的 live task queue。

- [`areaflow-vision.md`](areaflow-vision.md)：从旧 `scripts/question.md` 迁入的 AreaFlow 产品愿景、工作流优化需求和事故复盘资料；它是 non-current reference，不是当前执行标准、active backlog 或 release 阻断项。当前 AreaMatrix 的提问入口见 [`../intake.md`](../intake.md)。
- [`execution-hard-migration-plan.md`](execution-hard-migration-plan.md)：`tasks/prompts/**` 到 `workflow/versions/<version>/execution/**` 的脚本硬迁移方案与执行记录。

当前 AreaMatrix workflow 标准以 [`../architecture.md`](../architecture.md)、[`../pipeline.md`](../pipeline.md) 和 [`../execution.md`](../execution.md) 为准。
